# JustSVG · 模块品牌资源

本套使用用户上传图片中的右侧模块标志，未重新设计符号。原图见 source/uploaded-two-logos.png。原图按嵌入配置转换后的 sRGB 主体色为 #334256，原始通道值为 #273244。SVG 为原图边界的忠实矢量化，原始位图保留用于复核。

## 使用

- svg/：标志、横向/纵向组合、应用图标、favicon、传播素材与可编辑图表示例。标志与字标全部为路径，无字体依赖。
- png/：透明标志与传播素材。
- icons/：16–1024 px 应用与浏览器资源；不改变符号轮廓。
- applications/：当前官网与编辑器在独立浏览器上下文中的品牌预览截图。只注入此方案的标志与配色，未更改产品文件。
- brand.json / tokens.css：颜色、字体与规则的机器可读定义。
- fonts/：项目现有 JustSVG Sans 子集及 SIL OFL 1.1 许可；部分中文字使用系统字体回退。
- brand-book.pdf：八页品牌手册；完整文件列表见 asset-manifest.json。

## 基础规则

安全留白为符号高度的 1/4；导航建议至少 24 px，16 px 仅用于 favicon。只等比例缩放，不旋转、不改变内部间距、不叠加描边或阴影。

横向组合的字标高度为符号高度的 52%，间距为符号高度的 29%。应用图标为 1024 px 画布，符号为 592 px，四边留白 216 px。

强调色为 #0f766e，白字对比度 5.47:1。正文使用原图墨色，避免以强调色替代全部文字。

产品名称：JustSVG。主张：Just diagrams. Just SVG. / 把复杂系统，画清楚。
