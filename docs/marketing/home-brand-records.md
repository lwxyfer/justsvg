# 第二屏：品牌唱片

用户已选定当前版本作为唯一默认首页。入口为 `/`，品牌章节为 `/#brand-styles`；无需预览参数。旧 `BrandStage.tsx`、品牌切片样式、旧图形构图分支和“查看原版”入口已删除。历史预览参数不再控制页面版本。

候选从现有品牌 manifest 动态读取全部风格（本次 36 种），使用现有原生 SVG 文件作为封套图稿，不生成虚构模板或位图封面。前排依次是 Vercel、Linear、Stripe、OpenAI、Figma、Spotify、Claude、Google、Dropbox，其余保持目录顺序。

用户否定第一版“悬停后抬起”的手感，并明确选择“横向拨动：鼠标一划，封套连续侧翻，相邻封套跟着让位”。当前实现以一个连续的小数播放位置驱动整排封套：鼠标每移动一小段就改变侧翻角度，前后封套对向转动，同时调整间距和前后层次。命中坐标来自未变形的固定节距，消除旧版当前大封面内约一张宽度的交互死区；不再由离散 active 状态触发整张升起。

`useRecordDeck` 使用 GSAP quickTo 平滑追随，快速反向划动直接改变目标，不等待旧动画。每帧直接更新变换，React 仅在跨过风格中线时更新文案/全页预览。靠近两端可连续平移浏览其余唱片；离开、隐藏页面或卸载时停止平移并清理动画和监听。触屏原生横滑连续更新封套，开始手动操作时立即接管程序滚动。减少动态效果时直接更新位置，关闭边缘自动平移。

点击或 Enter 固定预览，离开后恢复固定项；未固定则恢复首页原色。支持横向滚动、触屏横滑/点击、前后按钮，以及方向键、Home、End、Escape。触屏 pointerleave 不触发鼠标的离开还原，避免刚操作就跳回上一个固定项。

全页预览采用目录纸色、可读文字色、对比色和圆角，少数风格另适配字体。现有三个完整首页图形主题仍沿用原实现；新增品牌主要展示真实目录图稿与全页配色，**不宣称下游 Skill/迷你编辑器已经实现所有品牌的独立构图**。固定指当前首页的风格预览，不写入持久存储。查看图稿进入对应的真实示例页。

新增实现集中在 `src/home/BrandRecordsStage.tsx`、`useRecordDeck.ts` 与 `brand-records.css`。不引入新依赖；第一、三、四屏、Footer 和完整编辑器保留已选定的实现。

验证：构建、定向 ESLint、diff 检查通过；回归以默认 `/` 的品牌唱片交互和既有编辑/导出流程为准；旧切片专属的两项测试已移除，其覆盖由唱片交互测试承接。覆盖同一风格内的小幅移动、相邻对向翻转、快速反向重定向、边缘翻阅/离开停止、固定/还原、键盘边界、真实触屏滑动、触屏点击与减少动态效果；桌面/手机截图位于 `.impeccable/review/home-records/`。这些验证确认交互执行，不代表用户已认可动效手感。
