# JustSVG design

## Overview

JustSVG is the user-selected identity for an open-source, SVG-native diagram creation and editing tool. Its subjects are architectures, flows, infographics and the structure of technical frameworks, products and repositories. Start from styles/templates or imported SVG, edit directly, and retain portable SVG. The diagram-first purpose governs the visual language rather than general vector illustration.

**Just diagrams. Just SVG.** / **把复杂系统，画清楚。**

The user's pinned light, professional desktop editor direction governs. Mode: Operate.
Three columns: 232px layers, flexible native SVG canvas, 280px inspector. A 56px file bar, 44px action bar, 30px status bar. At narrower desktop widths panels collapse independently.
System sans-serif UI; monospace for coordinates, XML and numeric measurements only. Neutral white surfaces, pale gray canvas, #2563eb interactive blue. Fine 1px dividers, 4–8px control corners, no decorative cards. Lucide icons at 16px. Tooltips include shortcuts. Focus-visible outlines, semantic controls, explicit disabled states.
The default authored example is an editable architecture diagram with clear groups and internal gradients/markers. It demonstrates the actual document engine, never a raster mockup.

## Layout

The separate `/examples` surface extends the same compact light workbench. Its 64px header carries the app identity, Example label and return-to-editor link. Desktop uses a 240px style rail, flexible preview column and 360px source panel, separated by fine dividers. Each column scrolls within the viewport. At widths up to 1200px, the rail and source panel narrow to 200px and 310px; the main heading stacks above its primary action so the workbench remains usable. At widths up to 800px, the page scrolls vertically: a horizontally browsable style rail comes first, followed by the preview and then the source panel. The mobile preview stage remains 370px tall and supports internal scrolling at 100% size.

The style rail presents 32 thumbnail rows with names, summaries and example counts, and its heading reports 32 styles and 73 examples. An All / 品牌风格 · 10 filter limits the rail to the ten brand studies; choosing a non-brand example restores All. The long rail scrolls vertically on desktop and compact desktop, and horizontally on mobile. Selection and rail resizing bring the selected row into view, including after a responsive layout change. Factory occupies the first rail position and carries the recommended label. Four visual variants follow the standard base style in the rail: 基础·技术文档 (`base-reference`), 基础·黑白线框 (`base-wire`), 基础·分区白卡 (`base-zone`) and 基础·深色工程 (`base-night`). Recommended shortcuts list factory, standard 基础风格 and 基础·技术文档 in that order. Technical documentation contains six examples, with two reference reconstructions before the four paired contents. For the four paired base contents, a 同图风格 control above the preview compares standard, wire, zone, night and reference while retaining the same diagram. The center pairs the selected style heading and open action with an example selector, SVG download, pale gray preview stage, dimensions, palette swatches and a short content note. The right panel contains Prompt/SVG tabs, an editable textarea, the active tab's copy or preview action, feedback, and explicit local-save/reset actions. This is a tool surface with plain panels, not a gallery of decorative cards.

## Components

**JustSVG identity.** A blue J-shaped route (#2563eb) connects a dark-ink square and circle (#19243b). The font-free symbol is native path/rect/circle geometry in a 64×64 viewBox, with a round-ended 8px route. Standard, monochrome and inverse assets preserve this construction; the inverse uses a white route and light-blue nodes (#86a9ff). Prefer a 24–32px mark, preserve legibility at 16px and leave at least 8/64 of its width as clear space. Keep its proportions and orientation; do not add decorative shadows or gradients. The editable-text wordmark pairs Just at weight 450 with SVG at 700, using local Helvetica Neue/Arial fallbacks. `src/components/Brand.tsx` supplies the shared mark and identity for the editor and Example headers.

The canonical native assets are `public/brand/justsvg-logo.svg`, its `-mono` and `-inverse` variants, `justsvg-wordmark.svg`, `justsvg-wordmark-inverse.svg` and `justsvg-brand-board.svg`. `public/favicon.svg` adapts node contrast to browser color scheme. The README uses the inverse wordmark for dark media and the standard light fallback. Title, application metadata and package naming use JustSVG; the previous SVG Finisher name appears only in migration/history. Existing `svg-finisher.*` storage keys, internal drag/drop MIME and `data-sf-*` metadata retain their compatibility identifiers. The identity extension preserves application geometry, controls and diagram artwork; product positioning does not assert full draw.io parity, domain ownership or exclusive trademark rights.

**Example navigation.** The editor opens the library on `/examples`; its identity link and return action lead back to the editor. The selected example is reflected in the `example` query parameter. **Native preview and source.** The preview renders sanitized native SVG in an isolated shadow root. Its fit/100% toggle supports both overview and detailed inspection. ResizeObserver updates the fit when the viewport changes and disconnects on cleanup. At narrow widths, including 633px, the full artboard remains visible in fit mode; 100% retains the selected artwork’s native dimensions with internal scrolling. Dense diagrams use fit for orientation and 100% for reading. **Explicit version state.** Editing SVG source leaves the last validated preview visible, shows a pending notice and disables open/download until preview or save succeeds. Invalid or unsafe source retains the previous preview and displays an error. Saving validates and stores the current SVG and Prompt as a browser-local override; reset removes that override and restores the built-in pair. Distinguish built-in, unsaved and saved states in text. Prompt copy reports success or selects the text for manual copying when clipboard access fails. Success, pending and error feedback uses restrained green, amber and red notices with status/alert semantics. Source tabs support arrow, Home and End keys alongside pointer activation.

## Do's and Don'ts

- Use JustSVG as the current product name and preserve the native J-route/two-node identity across editor, examples and exported brand assets.
- Keep the pinned editor's light compact chrome, blue interaction cues and existing document behavior when extending the library.
- Keep visual style distinct from diagram content type. The five base styles preserve text content, node geometry, groups and connections while allowing style-specific text alignment; brand scenes preserve semantic content and relations while using independent layouts.
- Keep artwork style independent from application styling, and show real editable SVG rather than raster substitutes.
- Keep example overrides explicit and local; editor changes do not automatically update the library, and leaving the library does not persist unsaved drafts.
- Describe the examples as authored demonstrations and prompts as reusable starting points; do not imply production data or exact AI reproduction.
