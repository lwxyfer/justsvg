# JustSVG

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + TypeScript + Vite, as recommended by the user. Lightweight supporting libraries chosen autonomously per explicit authorization.

## Users

Developers, technical writers, product builders and researchers creating architecture diagrams, flowcharts and infographics for systems, frameworks, products and code repositories; including refinement of AI-generated SVG.

## Product Purpose

An open-source, SVG-native diagram creation and editing tool, positioned as an alternative to draw.io. Core subjects are architecture diagrams, flowcharts, infographics, technical frameworks, products and code repositories. Start with brand/scene styles and templates, or refine AI-generated SVG. SVG is the portable document format; this is not a general-purpose vector illustration editor.

## Operating Context

Desktop browser, local files, no server or account. Choose a scene/style/template or import SVG → create and edit a diagram → export standard SVG.

## Capabilities and Constraints

Native SVG DOM, sanitization before rendering, isolated editor overlays, transaction history. No full illustration tools, AI integration, or cloud collaboration.

## Brand Commitments

Professional compact light three-column editor; white and gray surfaces, blue selection. Familiar Figma/VS Code/draw.io interactions. The user's precise visual brief governs the implementation.

## Product Principles

Import fidelity first; non-destructive edits; direct manipulation; semantic grouping; small and reliable.

## Evidence on Hand

Working editor with native SVG, multi-document tabs, local recovery, bound connectors and a style/example library. The user selected the name JustSVG. Tagline: Just diagrams. Just SVG.
