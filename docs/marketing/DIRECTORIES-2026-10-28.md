# JustSVG 产品发布社区与导航投稿补充

核对日期：2026-10-28。仅调研与方案更新，未注册、提交、联系或付款。适配与优先级是本项目的判断；平台声明不等于流量或录用承诺。仅发现表单不等于已经完成提交，未显示价格不等于永久免费。

## 新增渠道的任务

产品发布社区用于以作者身份介绍产品并获得讨论；软件/AI 导航用于建立持续可发现的产品条目。将它们作为独立分发工作，不混在评论获客中计数。它们能否带来 GitHub 关注仍需实测。

首月建议总投入：案例内容 40%、需求发现与定向参与 20%、产品发布与导航 15%、策展投稿 15%、复盘 10%；中英文各占一半研究和分发时间。

## AGICamp 材料方向

产品名保持 JustSVG，创作者使用本人稳定昵称。建议一句话为“用 AI Skill 生成技术图，直接编辑原生 SVG”。产品说明明确外部 AI 代理依赖、开源许可、当前 beta 与功能边界。

统一准备作者简介、产品短/长介绍、公开体验与 GitHub 链接、Logo、三张实际截图及一段完整操作演示；提交前对照当前表单检查素材规格。展示顺序为真实内容 → Skill 生成结果 → 编辑文字/位置 → 导出 SVG。准备作者开场，解释为什么做、当前适用任务和希望收到的反馈；个人经历须来自用户事实。

平台提交可能直接触发审核后公开，因此“提交审核”属于外发动作，不作为保存草稿操作。此轮只准备方案。

## 两批验证方式

1. D1–3：建立统一双语资料包，检查产品是否已被收录，记录每站入口、费用、AI 资格、登录和素材要求。
2. D4–7：从合格免费/可接受条件渠道中选首批，中文、英文各最多 2 个；完成授权后才提交。来源不同就调整开场和分类。
3. D8–14：检查实际状态与公开页面，再做第二批；首轮最多测试 6–8 个合格站点，不用购买收录或堆友链凑数。免费渠道不足就减少数量。
4. 上线后 7/14/30 天分别记录有效访问、仓库访问线索、独立分享与真实复用。审批耗时与无人回复单独记录，不写成渠道无效。

台账状态：待核对 → 资料齐备 → 已提交 → 待审核 → 已收录/拒绝/需补充 → 效果观察。每条保留提交日期、确认凭据和实际公开 URL。账号、验证码、付费或友链条件分别记录；不得默认接受营销邮件订阅或额外付费。

投稿包同时保留体验入口、GitHub 和作者主页；表单只有一个链接时按字段含义填真实产品地址，再在允许的说明或源码字段提供仓库。个人主页链接也须符合站点用途，AlternativeTo 用户主页不用于产品广告。其官方链接通常不允许 UTM，该渠道用可获得的 referrer 汇总观察；其他来源参数同样只能辅助归因，无法精确追踪哪个访问者点了 Star。

## 对原方案的修订

保留案例作为主要传播材料，将产品发布社区与导航列为独立渠道。它们适合没有社交资源的起步阶段，但目前没有证据证明本产品可从某站获得多少访问、Star 或关注。付费导航在免费路径出现有效信号后再评估，不采购批量代投服务。
