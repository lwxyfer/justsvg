# 基础风格变体：同图对照

“风格”指图形的视觉规则；架构图、流程图、信息图是内容类型。上一轮将三种内容类型列为风格分类，未满足用户需求，现已纠正。

## 五种视觉规则

| 视觉风格      | 分组与节点                                                   | 边框与圆角                                    | 连线表达                                            |
| ------------- | ------------------------------------------------------------ | --------------------------------------------- | --------------------------------------------------- |
| 标准基础      | 白底分组，节点按职责浅色填充                                 | 1.4px 细边框，8px 圆角                        | 同步蓝灰、异步琥珀虚线、数据绿、治理灰虚线          |
| 基础·黑白线框 | 纯白分组与节点，石墨色文字，取消语义填色                     | 方角节点，虚线分组边界，1.2px 轮廓            | 用粗细、虚线与点线区分关系，适合文档与打印          |
| 基础·分区白卡 | 语义色移至父分区，子节点统一白色                             | 分区无外框，白卡1.1px浅轮廓、12px圆角，无阴影 | 保留基础语义线色与线型                              |
| 基础·深色工程 | 深蓝画布、深色分组和实底节点，浅亮文字                       | 1.2px边线、4px小圆角，无发光                  | 亮蓝灰同步、琥珀异步、薄荷绿数据、浅蓝灰治理        |
| 基础·技术文档 | 近白画布，浅灰、浅紫、浅蓝、浅黄、薄荷绿节点；标题与正文居中 | 2px深色语义边框、8px圆角、彩色虚线父边界      | 灰色普通依赖、蓝色数据、橙色异常/异步、虚线治理关系 |

这四款样式分别改变色彩归属、容器与节点外观、边界语言和关系线型。内容文字、节点坐标、分组与连接关系保持一致；技术文档样式的文字改为居中排版，能够对同一张图直接比较。

## 同一套内容覆盖五种风格

| 内容                              | 画布        | 节点 / 关联连线 |
| --------------------------------- | ----------- | --------------- |
| 多租户 SaaS 平台 · 高信息密度架构 | 1600 × 1100 | 38 / 30         |
| 三层业务系统 · 基础架构           | 1200 × 800  | 9 / 8           |
| 发布交付流程 · 含失败回路         | 1400 × 900  | 10 / 10         |
| 请求生命周期 · 可观测性信息图     | 1400 × 900  | 12 / 5          |

四张标准图归入「基础风格」，连同原有24个组合图共28份内容。四种真正的视觉变体各自提供同样的四张内容，共16份样式稿；技术文档还含两张用户参考图复刻。其余17份RAG风格与本地版本保留，含十份独立品牌风格，目录总计 **32种风格、73份示例**；知识工厂仍为默认入口。

左侧选择风格；示例下拉选择内容。「同图风格」一行可在标准基础、黑白线框、分区白卡、深色工程、技术文档之间切换，保留当前内容、100%查看状态和滚动位置。左侧切换这五个风格也优先保留当前内容。原先「基础·分层架构」「基础·流程编排」「基础·技术信息图」不再作为风格分类。

## 高密度架构与复用

五条水平层带分别为用户入口、接入边界、业务域、异步集成、数据存储；右侧为共享治理运维。含缓存、事务、附件三条跨层连接；交叉且无圆点的线表示不连接。图示为代表性职责与依赖，不是完整生产部署或容量方案。

其他三张内容分别用于三层职责说明、发布判断与返工/回滚、请求阶段和Trace/Metrics/Logs字段矩阵。高密度图适应模式用于看整体，100%模式可滚动检查细节。

每份图有独立SVG与完整Prompt，包含对应风格、节点内容、坐标与连接路径。打开编辑器会新增图稿，文字、分组、判断菱形与连接继续编辑；移动可能由编辑器重新路由，不提供自动避障。

同图切换比较的是内置示例的视觉稿；各版本的草稿和本地保存独立保留，不会将一张自行修改的SVG自动转换成其他风格。现有图稿和本地数据不清除。

## 源码与生成

- 注册：`src/examples/base-variations.ts`，使用`sourceId`标识共同内容。
- 视觉规则：`scripts/base-style-themes.mjs`。
- 图形与几何：`scripts/generate-base-variations.mjs`。
- 原稿：`assets/base-*.svg`；变体：`assets/base-wire-*.svg`、`base-zone-*.svg`、`base-night-*.svg`、`base-reference-*.svg`。
- 对应Prompt位于`src/examples/prompts/`，同名Markdown。

```sh
node scripts/generate-base-variations.mjs
```

生成器从同一份图形定义生成5种风格×4套内容共20份原生SVG，不解析或改写用户导入的SVG，也不通过字符串替换XML改变样式。视觉差异在构造属性阶段应用；ID和内部引用按每份图独立命名。没有位图、外部字体、脚本或新依赖。

单元验证安全结构、引用、往返与五套视觉的内容/几何/关系等价；浏览器验证20份图的文字边界和线不穿节点/文字、下载、编辑重导入，以及同图切换和视口保持。截图：`tests/base-visual-comparison.png`、`tests/style-base-*.png`、`tests/base-style-*-desktop.png`、`tests/base-style-user-633.png`、`tests/base-style-mobile.png`。

两张参考复刻使用独立生成器，不纳入同内容配对。详见 [参考风格说明](REFERENCE_STYLE.md)。
