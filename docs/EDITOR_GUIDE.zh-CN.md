# JustSVG 编辑器使用指南

[项目介绍](../README.zh-CN.md) · [English overview](../README.md)

本指南介绍当前 beta 编辑器的具体操作、文件恢复和 SVG 兼容边界。先按 [快速开始](../README.zh-CN.md#快速开始) 启动项目，再进入 `/editor`。

## 使用方法

1. 点击「打开文件」可多选导入 `.svg`，也可把多个文件拖入画布，或点击「粘贴 SVG」输入完整 XML。焦点在画布时，⌘/Ctrl+V 也能导入外部 SVG 文本。
2. 单击图形或卡片分组选择，Shift+单击多选，Shift+拖动背景框选。双击分组进入子层级，顶部面包屑显示当前层级；Esc 退出。Alt+单击直接选择子元素。图层树可以选择被遮挡的元素。
3. 拖拽移动，拖动四角控制点修改尺寸；带矩形外框的节点只调整外框，内部文字、图标和描边保持原有尺寸。Shift 拖拽约束移动轴或保持宽高比例。方向键移动 1 个文档单位，Shift+方向键移动 10 个单位。
4. 双击文字直接编辑，或在右侧文字面板逐段修改。普通文字输入换行会生成多行 tspan；已有 tspan 逐段保留其属性及位置。右侧支持字体、字号、字重、对齐及多行行距；简单逐行文本可以增加/删除末行、按指定宽度换行，或缩小字号适应宽度。排版宽度使用文字本地坐标，仅在主动点击命令时生效。
5. 右侧修改文档坐标、外接矩形尺寸、相对旋转、透明度、填充、描边、圆角、ID 和 Transform。每个属性模块可点击标题独立折叠，「布局」默认展开。样式栏显示计算样式，修改时创建显式覆盖（inline `!important`），清空恢复继承。字号可直接输入数字，按 px 应用。
6. 多选后使用顶部对齐、均匀分布、相同尺寸、分组、取消分组与层级工具。均匀分布按元素之间的净间距计算。右侧「对齐与间距」可切换选择边界、关键对象或画布参照，并设置精确净间距。选中 line/polyline 后直接拖动端点或拐点；右侧可选择文档已有 marker 或创建实心、开放箭头及圆点。
7. 图层树提供搜索、隐藏、锁定、同父级拖动排序和双击名称重命名。画布选中子元素时自动展开必要祖先；多选后可批量隐藏或锁定。右键画布可按边界列出当前位置的重叠对象。隐藏会写入 SVG 并能撤销；逻辑名称使用 `data-label`。锁定属于会话设置，不写入 SVG，在撤销/重做时保留。
8. ⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做。使用「导出」下载 SVG 或图片、复制源码；通过 Header「源码」编辑完整 XML。源码修改先解析和安全清理，点击「应用修改」才生效，一次应用可撤销，并保留此前历史和视口。导出的文件可以直接在浏览器打开，也可以重新导入编辑。

按住空白处拖动会创建选择框，Shift+拖动可追加框选；单击空白取消选择，Esc 可取消进行中的框选并恢复原选择。按住元素拖动仍移动元素。Space+拖动或鼠标中键拖动可平移视图，双指/滚轮默认平移，Ctrl/Cmd+滚轮或触控板捏合缩放。连续滚动按帧合并，保留全部位移；缩放灵敏度比此前提高约 20%，缩放锚点保持在指针位置。画布设置取消「仅 Ctrl / Cmd + 滚轮缩放」可改为普通滚轮缩放。底部保留 Fit、100% 和倍率控件。设置弹框底部提供快捷键帮助。输入框获得焦点时，全局编辑快捷键暂停。

编辑器内部复制保留所需 defs、继承样式及内部引用；重复/粘贴后会为资源 ID 重新命名，并隔离粘贴的 CSS。剪贴板权限不可用时，「更多排列操作 → 粘贴元素」仍可使用当前会话内的复制内容。外部完整 SVG 在新标签中打开，原图及历史保留；安全清理会删除内容时，先展示影响供检查或取消。

## 多文档标签

工具栏下方的文档标签可同时打开、编辑和切换多张 SVG：

- 「打开文件」、粘贴完整 SVG、拖入文件及模板的「作为新图稿」都会新增标签，不覆盖原图。标签右侧的 **＋** 新建 1000 × 700、白色纯色背景的 SVG，初始名称为 `untitled`；右侧画布面板的「文档名称」可修改名字，名称同步到标签、恢复副本和导出文件名。最多同时打开 20 张图稿。
- 每张图独立保留原生 DOM、撤销/重做、选中对象、编辑层级、会话锁定、缩放、平移和比例锁定。图层与属性面板跟随当前图稿；素材库与全局偏好共用。导出、源码和编辑快捷键作用于当前标签。
- 标签显示完整文件名提示、未导出修改圆点和关闭按钮。长标签省略显示，多标签横向滚动，切换或窗口变窄时保持当前标签可见。聚焦标签后可用左右方向键、Home/End 切换，Delete/Backspace 关闭，不会误移动或删除图形。
- 关闭有未导出修改的图稿时，可保留图稿、直接关闭或下载并关闭。关闭最后一个标签后留下可用的空白图稿。
- 本地恢复副本原子保存所有已打开图稿、活动标签、未导出状态及各自视图；兼容旧版单文档记录。刷新后恢复内容和视图，撤销历史、选中状态和会话锁定重新开始。恢复失败保留原始记录并提示，容量不足不覆盖上次有效副本；请分别导出需要长期保存的图稿。

「导出 SVG → 恢复上一份文档」作为旧版恢复入口保留；如该文档仍在标签中，会直接切换到它。

## 补充图形和 Icon

左右侧栏始终显示。左侧默认显示「插入」面板，顶部可在「插入 / 图层」之间切换；未选中元素时，右侧显示画布设置；选中元素后只显示对应属性。插入后素材库保持展开，便于连续添加对象。切换偏好保存在本地，旧版图层偏好会迁移到默认素材面板。

- 在左侧「插入」浏览 **74 种图形**，分为基础图形、流程图、连接线、块状箭头、容器与注释、架构符号六类。包括开始/结束、子流程、文档、数据库圆柱、泳道、卡片、表格、云服务、消息队列等。点击插入视口中心，或拖入指定位置；进入分组时插入当前层级，随后立即选中。
- 「Icon 图标」提供当前依赖版本的 **1,903 个 Lucide 图标**，分为 18 类，覆盖设备、网络、开发与 AI、存储、安全、人物、文件、媒体、商务、医疗、交通等。保留 40 个常用精选和最近使用入口，支持中文关键词、英文名称及多词搜索，例如「数据库备份」「git branch」。部分名称保留英文。
- 分类以可折叠目录直接展示，默认展开置顶的「常用图形」12 项，包括矩形、圆角矩形、圆、文字、直线和箭头等；其余六类以及全部图形按需展开。Icon 同样提供常用图标、最近使用、18 类目录和全部图标。每次展开一个分类，常用图标每页 12 项，其余分类和搜索结果每页最多 60 项。搜索覆盖整个素材库，不受目录折叠状态影响；分类标题支持键盘方向键导航。图标矢量数据在首次打开 Icon 时从应用自己的静态文件按需加载，提供失败重试，加载完成后可断网继续插入，无图标 CDN 或外部 API 请求。图标默认锁定比例，右侧可整体改色和调整描边。
- 展开「导入自己的 SVG 图标」，选择本地文件或粘贴源码，将图标作为新对象插入，保留原图。内部 ID 和资源引用会隔离；多色图标保持原色，可深入分组编辑。
- 基础图形保留为可直接改属性的原生元素；图标使用命名分组和嵌套 SVG 保留 viewBox。每次插入可独立撤销。
- 矩形的「布局 → 外框宽度/高度」仅调整几何外框，不放大同组文字。组内多个候选矩形会分别列出选择入口。

## 使用组合图开始

左侧「插入 → 组合图」提供 **24 个可编辑模板 / 4 类**，常用模板置顶，支持名称和技术关键词搜索。

- **技术架构 8 个**：三层应用、微服务、RAG、事件驱动、CI/CD、数据处理平台、分层服务、可观测性。
- **工作流程 6 个**：审批分支、请求处理、异步任务与重试、故障排查、跨角色泳道、灰度发布。
- **技术信息图 6 个**：技术演进路线图、方案对比矩阵、指标卡、分层金字塔、数据生命周期、主题辐射图。
- **可复用组件 4 个**：服务信息卡片、双节点连接、服务集群容器、图例与状态说明。

点击预览将组合插入当前视口中心，也可拖到指定位置或当前分组内；一次插入可整体撤销，默认锁定缩放比例。点击「作为新图稿」以模板尺寸在新标签中开始，原图继续保留。双击组合进入节点层级，双击文字直接修改，Alt+点击可直接选择背景或连线。全部是原生 SVG 的分组、图形和文字，支持标准 SVG 下载和重新导入。

模板中的指标、负责人和对比结论使用待填写占位。新插入的内置模板已为端点明确的连线附带节点关联，移动和缩放卡片时跟随更新。完整目录、用法及开发约定见 [组合图说明](COMPOSITE_TEMPLATES.md)。

## 关联箭头与卡片

- **内置组合图**：进入组合后移动节点，已关联的连线及模板标签会随节点更新；缩放外框、方向键移动、对齐和分布也会更新连线。整组移动时不会重复偏移。
- **已有 SVG**：选中卡片或多个节点，在右侧「连接关联」点击「关联相邻箭头」。只关联屏幕上距离边界 14 px 内、目标明确的端点，保留原始端点间隙和走线；重叠目标不作猜测。导入本身不会自动修改原图。
- **手动指定**：选择直线、折线或简单直角 Path；若连线和文字在独立分组中，可直接选中该分组。在「连接关联」分别指定起点、终点节点，并选择最近边界或上下左右中心。节点没有 ID 时会自动添加唯一 ID。
- 一次卡片拖动与连线更新共用一条撤销记录。关联信息随标准 SVG 的 `data-sf-*` 属性导出，几何结果直接写入原生 SVG；重新导入后继续跟随。复制整个组合会隔离关联 ID；只复制连线时解除指向未复制节点的关联。
- 拖动线条端点会解除对应端的关联，另一端保留；单独移动连线会解除两端关联。也可从节点或连线的「连接关联」模块解除。删除节点后其端点解除关联，撤销可完整恢复。

支持 `line`、`polyline` 和仅含单一开放子路径的 `M/L/H/V` Path。曲线、多子路径、闭合图形及 CSS 控制的 Path 几何保留原样，不改写。折线维持直角和原有拐点通道，直线仍保持直线；不提供障碍物避让或整图自动布局。关联分组取消分组前需先解除引用，避免丢失连接目标。

## 图形动效

选中卡片、图形或连线，在右侧「动效」模块配置：

- **箭头流动**：支持带描边的 `line`、`polyline` 和 Path（包括曲线）。选择一条线，或只包含一条线及文字的分组；可调周期、正反方向、流动线段和间隔。保留原线作为轨道，关联卡片移动后流动层同步更新。
- **呼吸 / 柔和闪动**：通过透明度强调卡片、分组、文字或图标；可调 1–20 秒周期、10–75% 强度，不改变位置或尺寸。
- 每个对象可独立启用、停用或移除；参数修改支持撤销/重做。点击「编辑原图形」继续修改原对象的文字、颜色或端点。动效以原生 SVG 分组和受控 CSS 保存，不嵌入脚本。
- 顶部播放/暂停按钮或动效面板中的「暂停预览」控制全部预览，不修改源文档。画布外对象和不可见页面暂停播放；系统开启「减少动态效果」时显示静态。
- 正常下载或复制源码会保留动效，直接在浏览器打开 SVG 即可播放，重新导入可继续配置。用于文档或打印时，选择「导出 → 下载静态 SVG」；这会去除动效，保留原图和后续几何编辑，编辑中的配置仍保留。

当前每个对象配置一种动效，不提供时间轴、事件触发或视频/GIF 导出。任意第三方 SMIL 和 CSS 动画仍会清理；仅保留本编辑器经验证、重新生成的动效规则。若新增分组会改变原 SVG 的层级样式，操作会回滚并提示；由 CSS 控制几何或变换的线条暂不提供流动效果。Safari 尚未验收，文档软件对 SVG 动画的支持取决于其渲染器，可使用静态版。

## 安全与兼容性

SVG 是不可信输入。所有文件、源码、恢复文档和粘贴内容先经 XML 解析、额外校验和 **DOMPurify** SVG 清理后才进入可见 DOM。

- 禁止 DTD/实体、脚本、事件属性、不受支持的命名空间和危险 URL。
- 禁止外部图片、字体、样式、链接资源；仅允许内部 `#id` / `url(#id)` 引用，以及嵌入的 base64 PNG/JPEG/WebP。
- CSS 用 **CSSTree** 解析，按属性白名单保留，去除外部 URL、@规则、转义、变量及不支持的内容。安全的渐变、marker、filter、clipPath、mask、symbol/use 和常见样式正常保留。
- foreignObject、第三方 SMIL/任意 CSS 动画、feImage 等高风险或暂不支持内容会被移除；编辑器动效只允许有效配置生成的固定规则，不放开任意 @规则或动画属性。链接容器解包保留可见子元素，并在状态栏报告。清理会改变不安全原稿的外观，报告不会将其宣称为无损导入。
- 检测 use 循环和过量展开。文档上限 5 MB、15,000 个节点、80 层嵌套；viewBox 坐标及尺寸限 100,000，避免异常输入冻结编辑器。
- 页面还有 CSP 作为额外防线。开发模式仅额外允许本机 Vite WebSocket。

以下是**明确的 MVP 限制**，操作时会提示或不提供对应工具：

- 不提供钢笔、复杂 Path 节点编辑、障碍物避让、全图自动布局、AI 生成、云端保存或多人协作。关联的直线/折线/简单 Path 可以随节点更新，复杂 Path 可整体变换和改样式。
- use 实例整体选择和变换；不展开其引用源进行内部编辑。defs 的内容不列为可拖拽图层。
- textPath、嵌套 tspan、混合直接文字/tspan、逐字坐标列表等复杂文本保留渲染，但不重写文字。带混合样式的平铺 tspan 保留逐段编辑；只有安全的逐行结构提供显式行管理。
- 带组透明度、滤镜、裁剪或蒙版的分组不能取消分组，因为这些合成效果无法普遍分发给子元素。跨父级分组不支持，需先进入同一层级。
- 分组/取消分组会将当前计算的视觉样式显式化以保留外观；移动会合成所选元素的 transform 矩阵；节点改尺寸优先修改外框几何，保留内部内容尺寸。其他节点保持原样。
- CSS Transform 保留显示，但直接使用 CSS Transform 的节点不提供几何变换、复制或重新分组；可选择其外层 SVG 分组变换。推荐在源文件中使用 SVG `transform` 属性。
- 引用中的 ID 不允许单独重命名，以免破坏 CSS/资源引用。剪贴板引用重写使用 CSS AST，而非 XML 字符串替换。
- 外接矩形不包含所有滤镜阴影和描边扩展；零宽/零高线条应通过端点属性编辑。极复杂第三方 SVG 不保证任意语义往返。
- SVG 使用本机字体；未安装字体会回退。没有 viewBox 且使用百分比/缺失尺寸时采用 800 × 600 工作视口并提示。
- 面向桌面浏览器；紧凑桌面可收起侧栏，窄于 760px 自动隐藏图层，窄于 540px 自动隐藏属性。没有实现手机专用编辑模式。
- localStorage 是便捷恢复，不是持久备份；全部标签共用浏览器存储额度，容量不足会提示，请定期导出。损坏的启动记录会报错，并在用户开始修改前保留原记录。刷新与重新导入不会恢复历史和会话锁定；当前会话内切换标签会完整保留。
- 默认没有持续自动换行或卡片自动重排；文字排版命令使用本机字体。新建箭头采用当时的描边颜色，后续改线色需重新选择箭头样式。
- 稳定 1.0 尚有待办：文字排版预览、属性来源的逐字段说明、大型图层虚拟化、侧栏宽度拖动、性能量化、Safari 与实体触控板验收，详见实施进度。


### 文件、工具栏与图片导出

- Header 左侧可直接粘贴 SVG，「导入」下拉菜单提供新建、打开文件和恢复文档；右侧提供示例库、源码、GitHub 项目链接与设置按钮。「导出 SVG」可直接下载，旁边箭头展开其他格式。
- 多文档标签位于编辑工具栏上方。左右侧栏不可关闭，窄窗口可横向滚动工作区。
- 「导出」支持标准 SVG、静态 SVG、PNG、JPEG、WebP。图片倍率可选 1×、2×、3×，按文档尺寸输出，不包含网格、选择框和编辑器界面。
- PNG/WebP 保留透明背景；JPEG 使用白底。图片使用静态图稿，保留当前 SVG 的动效配置与未导出状态。继续编辑时建议同时保存 SVG。
- 下拉菜单在点击外部、选择操作或焦点移出后收起；Esc 收起并返回触发按钮。


### 画布与元素属性

- 未选中元素时显示画布设置，已有图稿不再显示「粘贴你的 SVG」引导；点击图稿外空白可返回画布设置。
- 尺寸可直接输入宽高，选择 16:9、4:3、正方形或 A4 预设，也可交换宽高。修改范围为 1–16384 px；调整画布边界不拉伸已有图形，支持撤销。
- 画布背景支持透明、纯色、双色渐变、点阵、网格。渐变可改两端颜色和角度；图案可改底色、图案颜色及间距。背景写入原生 SVG，随 SVG/图片导出、重新导入与多文档恢复保留。
- 工作区底色与辅助点阵/网格单独设置，仅辅助编辑。画布背景与工作区背景用途在面板中分别标明。
- 选择元素后，常用布局和外观紧凑排列；动效和 SVG 属性按需展开；属性面板中的 Details 说明入口已移除。


批量导入按文件顺序打开独立标签，单个文件上限 5 MB。无效文件会列明原因并继续导入其他文件；需要清理的文件会逐份显示文件名与检查结果，确认或取消当前文件后继续处理其余文件。


### 编辑器设置与语言

Header 的齿轮按钮打开「设置」弹框，当前提供「简体中文 / English」选择。语言立即生效并保存在当前浏览器，重新打开和刷新后保留；地址中的明确语言参数与浏览器前进/后退同步。Esc、点击弹框外部或「完成」关闭设置。快捷键帮助位于设置底部。Header 不再显示 Beta 或重复文件名，文档名称保留在标签和右侧画布面板中；GitHub 图标在新标签中打开项目仓库。


### 节点尺寸、透明容器与图标颜色

- 拖动角点和修改宽高使用同一套尺寸逻辑。矩形外框改变 width/height，不对整个卡片缩放；文字字号、图标大小、描边和圆角保持不变。缩小后再次调整仍以外框为目标，内容可以溢出外框，不会自动缩字。一次拖动为一条撤销记录，Esc 取消整个拖动。
- 透明或无填充容器可从内部空白处悬停、选择和拖动，按图层前后顺序命中；支持嵌套坐标、Alt 深入选择与当前编辑层级。打开的线条路径保持绘制区域命中，避免其大范围外接框抢占背景。锁定与隐藏对象仍按原规则处理。
- 内置单色图标的「图标颜色」提供原生颜色选择器、即时预览和最近颜色；确认一次选色会合并成一条撤销记录，Esc 可取消未确认的选色。


连续平移只更新画布视口，避免属性面板和素材库随每个滚动事件重绘。操作不会改写 SVG 或创建撤销记录。浏览器连续滚动、分数位移、缩放锚点和框选均有回归检查；具体触控板硬件和 Safari 手感尚未直接验收。
