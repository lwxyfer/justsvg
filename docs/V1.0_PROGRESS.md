# JustSVG 1.0 实施进度

日期：2026-10-25。交付版本：**1.0.0-beta.1**。此版本可运行并完成完整导入、编辑、下载和重新导入流程；不将其标为稳定 1.0 发布。原始产品范围见 [需求清单](V1.0_REQUIREMENTS.md)。

## 本次交付

- 十个品牌风格：Apple、Microsoft、Google、OpenAI、Claude、Notion、Stripe、Linear、Figma、Vercel，已纠正用户否定的共用卡片版，逐一重建同语义、不同构图的原生SVG并验证编辑/导出/重导入；品牌筛选、官方参考链接、同图语义比较与完整Prompt齐全。
- 独立 Example 示例页：32种风格、73份示例。基础风格有28份内容；黑白线框、分区白卡、深色工程、技术文档是四种真正视觉变体，各有相同四张场景图。原先三种内容分类已撤销为风格分类；同图切换保留内容、坐标、连线和检查视口。技术文档另含两张用户参考图的可编辑复刻；高密度架构38节点/30连接继续可用，知识工厂保持默认，已移除示例不恢复，本地数据保留。
- 预览同时按宽高适应，633px 小窗口完整显示，缩放按钮不覆盖画布。

- 图形动效：箭头流动、卡片呼吸和柔和闪动，独立周期/方向/强度与启用配置、全局暂停预览、静态导出。动效随标准 SVG 保存，关联箭头继续跟随；按系统减少动态效果设置退化为静态。

- 节点与箭头关联：模板带明确端点关联，已有 SVG 可按邻近边界建立或手动指定；拖动、缩放、对齐同步更新直线/折线/简单 Path，保留单次操作历史和可导出的原生 SVG。

- 多文档标签：文件、源码导入与模板新建均新增标签；每张图保留独立 DOM、历史、选择/锁定、层级与视图，支持空白新建、关闭保护和全部标签刷新恢复。

- 左侧默认常驻「插入」面板，图层按需切换：74 种图形与文字，常用 12 项置顶，六类目录按需展开，点击插入视口中心或拖入指定位置，插入当前分组后立即选中。

- 24 个原生组合模板，分技术架构、工作流程、技术信息图、可复用组件四类，常用置顶、关键词搜索、大预览；点击/拖动插入当前图稿，或作为新图稿开始，内部节点和文字继续编辑。目录与使用边界见 [组合图说明](COMPOSITE_TEMPLATES.md)。
- 自定义 SVG 图标文件/源码插入，不替换当前文档；保留 viewBox、定义和多色样式，隔离 ID/引用及 CSS。
- 文字显式行管理、按宽度换行、缩小字号适配；采用原生 SVG 测量，临时测量节点不进入文档历史。
- 矩形外框几何尺寸编辑、分组背景候选入口，保留同组文字和图标尺寸。
- 对齐参照和净间距，line/polyline 的可视化端点/拐点，已有 marker 选择与独立箭头样式。
- 图层祖先展开定位、同级拖动排序、搜索路径、批量隐藏/锁定，右键选择重叠对象。
- 安全源码编辑：错误不替换文档，清理影响可检查，一次应用可撤销，原有历史和视口保留。
- 连续颜色预览与按住方向键微调的事务边界，字段内错误提示，模块/导航/网格/素材偏好保存。

## 重要实现取舍

- 用户文档继续以安全 SVG DOM 为源，未引入 Canvas/位图或专有图形模型。
- 基础图形插入为直接可编辑的原生节点；图标保留命名分组与嵌套 SVG，以保留自身 viewport/viewBox 语义。
- 插入素材先在独立 Shadow DOM 中解析视觉样式，再显式冻结所需视觉属性、重写内部引用，避免原图的 `path`、`rect` 等 CSS 意外改变新对象。
- 图标许可保留在导出 SVG 的 desc 中；用户文档自包含，无外部图标资源请求。
- 文件/完整 SVG 导入在新标签打开；源码面板应用仍是当前文档的一次可撤销修改。标签切换保留原生 DOM 与会话历史，不经 XML 重新导入；刷新恢复内容和视图，历史重新开始。
- 本地恢复与文件下载状态分别表达。浏览器下载 API 无法确认用户文件系统最终落盘，界面只报告已发起下载。
- 小动效使用可移除的原生 SVG 分组和固定 CSS keyframes，原图节点保持在分组内部。流动层只复制显示所需的几何与描边，不作为独立可编辑图层；隐藏、删除、关联更新与撤销同步处理。复制/分组不把动画中的透明度或偏移冻结为显式样式。
- 动效导入严格验证元数据，只按验证后的参数生成固定规则；输入里的样式标记本身不能绕过清理器。系统减少动态效果、全局暂停和可见性控制不需要嵌入脚本；静态下载不清除编辑中的配置，也不将其标记为完整导出。
