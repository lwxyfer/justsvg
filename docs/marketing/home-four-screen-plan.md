## 图形重建后的实现细节

首屏补齐三个 XML 面板、对齐辅助与尺寸标注，标题/选中框通过实际连接线延续到三组能力图解；品牌图解展示 Vercel/Figma/OpenAI，原生 SVG 图解保留 Bézier，编辑图解包含搜索 glyph、选择框、节点名称和填充属性。Figma 扩展态补齐周边圆/方几何、钴蓝弧线与大尺寸描边堆叠 LLM。

Skill 使用独立的左侧源链与横向 Retriever → Context → LLM → Answer，带六个 XML 面板和构造框；大型横向 SVG 文件轮廓内是完整九节点/八连线缩略图。交接路径实际连接任务、Documents、Answer、文件轮廓以及编辑器与导出文件，不是孤立装饰线。

`ConstructionConnections` 读取真实 DOM 几何，随 resize、相关 mutation、scroll 与字体就绪更新，并在卸载时清理 observer、listener 和 animation frame。交互编辑器仍为 200×78 节点；其实际 XML 导出契约保持不变。Figma 专属外层背景补齐 Skill 的右上珊瑚、左下淡紫与文件后黄色场，以及编辑器上方黄色、左下淡紫和稀疏点阵/辅助线；均为绝对定位的原生 SVG，置于可读内容之后，不改变排版流或拦截点击。上述章节图形是原生 SVG，未将参考位图放入运行页面。

## 风格与共享状态

默认 A 使用 `#f6f7f2` 纸色、`#152032` 墨色和 `#2855ee` 钴蓝。Vercel 为近黑工程网格/文件标注/直角，Figma 为奶油画布/黄紫薄荷角色色/组件几何，OpenAI 为暖色渐变/透明技术平面/轮廓弧线。主题通过首页根变量传递，JustSVG 标记仍保持辨识。

鼠标悬停 100ms 后预览，键盘聚焦立即预览；离开整个选择区恢复已锁定风格或默认。点击、Enter 或触屏点选锁定；重置回原生。“使用此风格”锁定当前主题并进入 Skill，原生默认状态选择 Figma。主题与图稿修改在模块内存中跨首页/编辑器路由保留，不承诺刷新持久化或小编辑器撤销栈恢复。

## Skill 获取与诚实边界

修改任务和选中主题组成真实完整指令，包含视觉参照与九节点语义要求。网页不调用模型，任务修改不会生成新示例；画面明确标注“示例演示 · 在 AI 代理中运行”。当前仓库的 `skills/svg-diagram` 已打包为 `public/skills/svg-diagram-skill.zip`，验证为 24 个文件、659218 字节；提供下载不代表已在外部服务发布。包中沿用的示例预览不作为首页位图素材。

## 编辑与导出边界

原生 SVG 直接接受节点选择、名称、颜色、位置修改；八条绑定折线随节点移动。方向键移动 5 单位，Shift 为 20；支持撤销和重置。打开完整编辑器会创建新的 `rag-system.svg` 标签并保留当前修改。打开完整编辑器时序列化实际显示图稿，移除选择框、构造和网页交互辅助，保留九个语义节点 ID、八个端点绑定、原生文字与分组。序列化在移除 class/UI 属性之前展平首页专用 `.node-shell` 包装，使背景形状成为语义节点的直接子元素，符合现有编辑器连接目标识别约定；节点 ID、矩形锚点和八条关联保留，编辑器引擎未改动。导出为静态可移植 SVG，不包含 GSAP 运行时，也不承诺旧版本的脉冲/流动动画。

## 动画、字体与响应式

GSAP 做首屏标注入场，以及五处 ScrollTrigger：原生构造、任务路径、图稿组装/文件显现、导出路径、文档闭合；当前无 pin 或自动翻页。首屏额外以一个信号点沿 Query 到 Answer 的实际连线缓慢传递，并在 Retriever 选框作轻微响应，轮次间停顿；首屏离开视野或标签隐藏时暂停，减少动态效果时移除，卸载时清理监听。右上角改为项目 GitHub 链接，主文案下的编辑器入口保留。减少动态效果覆盖首页根元素、后代与伪元素，取消过渡并不创建触发器；路由卸载清理上下文。正文、图稿与控件在静态状态仍完整可用。

JustSVG Sans 为重命名 Noto Sans SC 可变子集，147540 字节、OFL，承担首页重字重标题与页面文字；原有标记字标、编辑器和示例作品字体独立，SVG 导出使用系统回退字体。旧 serif 文件未被当前首页导入；无运行时字体服务。GSAP 与 React 适配依赖沿用已有版本和 Standard License，无新增运行时依赖或首页位图。

内容最大宽度 1440px；常规两侧各 56px，1200px 以下各 36px，900px 以下各 24px，600px 以下各 20px。窄屏简化导航和图层栏、纵向安置属性，保持图稿完整范围，不凑固定四屏高度。
