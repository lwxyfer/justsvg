# 岗位业务示例

首批包含 12 个业务主题 × 2 种工作风格，共 24 份 SVG 与生成 Prompt。示例页增加「产品 / 财务 / 运营 / 项目协作」岗位快捷入口，与关键词、图形类型、风格系列取交集。一个示例可适用于多个岗位，部分同时标记设计或管理层。默认 OpenAI 入口和已有示例保留。

「工作·清晰评审」采用冷白底、无衬线、横向完整图形、浅色语义分区，强调责任、条件与细节。「工作·正式汇报」采用暖纸、衬线大题、左侧判断/协作/下一步、右侧主要图形和底部讨论目标。它们是同一业务内容的两套工作表达，不新增品牌。

## 财务数据编辑

1. 打开利润变化或预算实际示例，选择「打开编辑器」。
2. 单击图表，右侧首先显示「图表数据」。
3. 修改标题、统计期间、金额单位、项目与金额；选择「数值增加 / 数值减少」哪一种代表有利方向。
4. 点击「应用图表数据」，柱形、轴域、零线、数值标签、合计和有利/不利颜色一起更新。该操作只产生一条撤销记录。
5. 在编辑器导出标准 SVG。浏览器可以直接打开；重新导入 JustSVG 后保留数据编辑能力。

利润图以百分之一最小单位加总：期初 + 各增减项 = 期末，支持零值、负变化和负利润。预算对比要求预算/实际非负，使用相同轴域；差额为实际减预算，费用较少可设为有利方向，持平使用中性色。大金额的图上标签使用 K/M/B，合计和数据输入保留金额精度。

当前支持 2–8 个项目，金额最多两位小数、单值绝对值不超过十亿。非法或空白金额保留在表单里并提示，不写入文档。金额单位是显示口径，修改标签不进行金额或币种换算。统计期间同样是标注，不自动筛选数据。

数值标签由图表数据管理，直接改字会提示使用数据面板。图形仍能按普通 SVG 调整，但直接移动/变形不会改变源金额；下次应用数据会重排该图表。更新保留图表外层变换与其他节点。业务漏斗、路线图等其他示例仍是手工编辑图，修改文字不会自动计算比例或日期。

可选数据存于 `data-sf-chart` 的 URI 编码 JSON 中，经过版本、类型、长度、数量和有限数值校验；没有可执行内容。图形渲染完全依赖原生 SVG。外部工具若删除元数据，图形仍可显示与手工编辑，但不能使用数据面板重算。

所有示例情境、研究描述、日期和数字均为演示，正式使用应替换为真实资料；图表顶部的演示说明也可通过 SVG 文字编辑。首批尚未扩展销售、人力的独立场景或通用 BI 数据导入。

## 维护与验证

- 素材注册：`src/examples/business.ts`、`business-manifest.json`。
- 场景与生成器：`scripts/business-scenes/`、`scripts/generate-business-examples.mjs`。
- 生成：`npm run generate:business`，只重建 `business-` 资源。
- 图表计算/渲染：`src/editor/charts/financial.ts`；文档事务：`editing.ts`。
- 数据面板：`src/components/FinancialChartProperties.tsx`。
- 验证：`npm test`；`npx playwright test tests/e2e/business-examples.spec.ts`。

当前目录为 66 种风格、169 份示例、39 份品牌研究。原品牌与专题素材保持独立，不为每个岗位复制全部品牌版本。
