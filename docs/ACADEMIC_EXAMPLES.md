# arXiv 论文配图

入口：`/examples?example=arxiv-rag`，也可以在示例页搜索 `arxiv`、`论文` 或 `科研配图`。属于「专题风格」系列，图形类型为「架构图」；与其他 RAG 研究图可通过详情标题选择器切换。旧的「黑白论文」保留。

这个示例表现机器学习论文中的方法图语言：1440×900 白底，Times 系列衬线字体，(a) 离线索引、(b) 在线检索和生成、(c) 提示词放大三个分面；低饱和蓝/赭/紫表示检索、上下文和生成；细描边、明确的线型图例、数学变量和底部 Figure 图注。文字和线型使灰度打印仍能辨认关系。它是原创学术风格研究，不是 arXiv 官方视觉规范或论文模板。

9 个节点、8 条绑定连线都能继续编辑。打开编辑器后，可修改文字、移动节点、撤销/重做，再从编辑器下载 SVG。生成 Prompt 与图稿一起维护，可复制并替换研究主题。示例中的数据流是通用 RAG 说明，不声称复现下列论文的方法或实验。

参考阅读：[RAG Survey](https://arxiv.org/html/2312.10997v5)、[R²AG](https://arxiv.org/html/2406.13249v1)。这里只借鉴科研方法图的信息组织，不复制论文原图。

源文件：`src/examples/assets/arxiv-rag.svg`、`src/examples/prompts/arxiv-rag.md`，在 `src/examples/academic.ts` 注册。节点 ID 和 marker 都使用 `arxiv-` 前缀；文字保持原生 text/tspan，无外部图片或字体。数学下标使用 tspan；不同系统的本地字体仍可能有细微差别。当前设计适合论文双栏通栏图；单栏排印建议拆分分面或重新布局。

新增后示例库共 59 种风格、140 份示例、36 份品牌研究。应用界面和原有图稿不变。
