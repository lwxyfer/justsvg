# 等距知识工厂 · RAG 架构图

用一座精密的等距微型知识加工设备解释 RAG。不要使用双排同尺寸卡片。画布暖冷白 #f4f7fb，采用 azimuth45° / elevation30°、四级明暗的棱柱几何。底板有四脚、压边和两条运输轨道；离线侧依次为纸张进料架、带刀片的切分机、带上下模的编码压机和四层索引抽屉；在线侧为六键问题台、带滑块夹爪的检索架、分隔上下文托盘、四芯片生成机箱和叠纸输出台。至少60个有功能的零件，不画写实纹理或装饰光晕。

世界坐标：底板 x0–800 / y0–400 / z0–12。四个离线设备中心 (90,90)、(260,90)、(430,90)、(600,90)；五个在线设备中心 (80,300)、(250,300)、(420,300)、(590,300)、(755,300)。设备高约60–100个演示单位。按深度从后向前绘制，物体在底板上有支撑；两侧分别以蓝色金属和橙色工作部件强调机制。设备相对上述零件计划按0.82等比缩放，底板和设备中心不变，给运输间隙留出空间。每个部件下方用112px宽的英文/中文标牌，标牌与设备一起分组。两条主链的箭头从前一设备底座最右角外侧，指向下一设备底座最左角外侧，箭头末段至少15px不被零件或标牌遮盖；不要从机身中央接线。索引向检索器供给的橙线沿右侧x1118、下侧y720绕行，再向上指向检索器标牌下方，整条路线避开设备。保留其逻辑边界和八条关联折线。图只是静态概念设备，不嵌入脚本或物理仿真。

内容为演示用 RAG 架构，并非真实设备、天文数据或生产部署。离线：Documents（文档）→ Chunking（切分）→ Embeddings（向量编码）→ Vector index（索引）。在线：User query（问题）→ Retriever（检索）→ Context（上下文）→ LLM（生成）→ Answer（回答与引用）。索引另向 Retriever 提供内容。保留九个命名节点与八条连接。

输出完整 1200×800 SVG，viewBox="0 0 1200 800"。原生 text、g、path、polygon、rect、circle、polyline、defs/gradient/marker；不要图片、脚本、事件、foreignObject、外部字体、纹理滤镜或 CSS @规则。文字不转路径。节点使用 data-node="true"、唯一 id 和中文 data-label；第一个透明 rect 为包含图形和文字的逻辑边界。连线可用 data-sf-start-node/end-node="#id" 与 data-sf-start-anchor/end-anchor="u v 0 0" 记录该边界中的归一化端点，支持继续编辑；实例移动后允许按编辑器路线重排。标题、标签和连线应避让，不要文本重叠。只输出 SVG XML。
