# Example 示例库

入口：编辑器顶部「Example 示例」，独立路径 `/examples`。页面按风格组织预览、SVG 源码与可复用的生成 Prompt。每个示例都是真实的原生 SVG，可以下载并独立打开，不使用位图模拟。

现有十份品牌风格，左侧「全部 / 品牌风格」筛选用于定位。Apple、Microsoft、Google、OpenAI、Claude、Notion、Stripe、Linear、Figma、Vercel保留同一套RAG语义和依赖，各用独立版式，通过同图切换比较；下方显示非官方品牌灵感说明及官方参考链接，完整规则写入Prompt。详见 [品牌示例说明](BRAND_EXAMPLES.md)。

十七份风格示例统一使用 RAG 的离线索引和在线回答流程：9 个节点、8 条连线，包含向量索引向检索器提供内容的跨行连接。它们是说明用的简化架构，不代表完整生产部署、真实运行状态、设备规格、天文坐标或性能数据。节点命名、原生文字、marker 引用和节点关联均保留，拖动卡片可更新连线。四张标准内容各有四种视觉变体，使用同一内容和几何进行对照，详见 [基础风格变体](BASE_VARIATIONS.md)。目录共32种风格、73份示例；知识工厂、基础风格和技术文档提供推荐入口，旧风格页面的预览上方也可切换推荐。当前风格在纵向/横向长列表中自动滚入可见区域，窗口尺寸变化后仍保持可见。

手绘草图完全由原生 SVG 生成，不使用图片或纹理滤镜。手写字使用本机 Comic Sans MS / Chalkboard SE / Kaiti SC / KaiTi / cursive 回退，设备间字形可能不同；中文节点说明保留系统无衬线字体以便阅读。移动节点后连线仍可跟随，初始的细小起伏可能被正交路由重排；手绘边框与文本可作为整个分组缩放。

轨道星图与折纸数据流已从内置库移除，源码、Prompt 与生成器同步移除；旧链接回到知识工厂。已有编辑器图稿与本地保存数据保持原样。

## 选择与复用

1. 左侧选择风格。基础风格通过「示例」下拉选择具体图形。
2. 四张标准示例的「同图风格」可切换标准、黑白线框、分区白卡、深色工程和技术文档，保留内容和检查视口。查看原生预览；适应模式按可用宽高等比缩放，完整显示画布并预留缩放按钮位置，100% 模式可滚动检查细节。下载的是 SVG XML，画布 UI 不进入导出。
3. 「在编辑器中打开」会新增标签，保留原工作。返回示例页不清空编辑器历史、选择或视图；编辑器快捷键在示例页暂停。
4. 「生成 Prompt」包含主题、节点关系、视觉语法、尺寸布局和安全约束。可以替换主题与标签后复制到自己的 AI 应用。本应用没有 AI 调用；这些提示词是随示例维护的设计规格，不承诺确定性的模型输出。

## 调试与本地版本

- Prompt 和 SVG 源码均可编辑，切换示例保留本次页面内的草稿。
- 改 SVG 后点击「预览 SVG」；成功才更新预览。非法 XML、脚本、外部资源或需清理的内容会明确拒绝，继续保留上一张有效预览。单个示例源码限制 500 KB，Prompt 限制 60,000 字符。
- 「保存本地版本」先校验 SVG，再原子写入 `svg-finisher.examples.v1`。SVG 与 Prompt 成对保存，刷新后恢复；存储配额或损坏记录不会被静默覆盖。示例版本与 `svg-finisher.document` 的图稿工作区相互独立。
- 「恢复内置」清除当前示例的覆盖。内置素材本身始终保留在应用文件中。
- 离开页面前需保存想保留的 Prompt/源码草稿。编辑器中的修改不自动同步回示例库；可以将修改后的 SVG 源码粘贴回示例页预览并保存。复制权限不可用时，页面会选中 Prompt 供手动复制。
- 浏览器本地版本不随 URL 分享、不跨设备同步；重要修改请下载 SVG 并另存 Prompt。

## 开发维护

`src/examples/catalog.ts` 注册基础图，复用组合图本身；`styles.ts` 汇总额外风格，`more-styles.ts` 注册追加风格。`base-variations.ts` 通过 `sourceId` 关联标准与变体，`scripts/base-style-themes.mjs` 定义视觉规则。每种风格有独立的 `assets/<style>.svg` 与 `prompts/<style>.md`，保证提示词可以审查、复制和版本管理。预览在独立 Shadow DOM 中渲染，沿用文档 Sanitizer，不将 SVG CSS 注入应用页面。

原有五种素材与后续追加素材（含手绘草图）使用各自生成器，互不覆盖：

```sh
python3 scripts/generate-style-examples.py
python3 scripts/generate-more-style-examples.py
node scripts/generate-featured-examples.mjs
node scripts/generate-base-variations.mjs
node scripts/generate-reference-diagrams.mjs
node scripts/generate-brand-examples.mjs
```

如果需要保留对生成素材的手动修改，请同时修改对应生成器；再次运行会重写该组 SVG 和 Prompt。第二个生成器复用第一份脚本的主题与约束定义，泳道等有不同布局的风格保存独立布局说明。更复杂的后续原创素材可以直接独立注册，不必使用此生成器。静态部署时需配置 SPA fallback，使 `/examples` 回退到 `index.html`；部署子目录时沿用 Vite `base`，导航路径会随之调整。

推荐示例注册在 `featured.ts`，构图及零件计划见 [推荐示例方向](FEATURED_EXAMPLE_DIRECTION.md)。知识工厂的投影/棱柱几何复用 MIT 许可的 anatomy 生成辅助库，源码及许可在 `scripts/vendor/`，仅生成时使用，不进入浏览器运行依赖。生成器检查 88 个静态棱柱零件的支撑连通关系，按部件投影和标牌计算逻辑边界；这是静态接触检查，不是运动、碰撞或真实物理仿真审计。输出仍为普通 SVG，可脱离编辑器显示。复杂构图节点移动后，语义端点继续跟随，连线可能按现有编辑器路径重排。
