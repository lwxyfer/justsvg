# JustSVG 1.0 需求与优化清单

日期：2026-10-24
状态：1.0 产品范围；研发已开始，实际交付与差距见 [实施进度](V1.0_PROGRESS.md)。
依据：当前源码、README、已有验证记录，以及本轮已确认的实际使用反馈。

本文用于定义下一阶段交付，不将需求描述作为完成声明。仓库 package.json 中的版本号不代表产品已达到本文件的 1.0 发布标准；当前实现版本为 1.0.0-beta.1，尚未达到稳定 1.0 的全部发布门槛。

## 1. 版本目标

让用户在不理解 SVG 源码、不切换选择/手型工具的情况下，稳定完成 AI SVG 最常见的精修：**改文字、修换行、调整卡片尺寸与间距、修改样式、修正连接线、补充常见图形和 Icon，并放心导出。**

1.0 的重点是编辑深度、操作效率和可恢复性。继续以安全处理后的 SVG DOM 为文档源，保留原生结构与资源引用。

### 已确认、不得回退的交互

| 项目     | 1.0 必须保留的行为                                                                   |
| -------- | ------------------------------------------------------------------------------------ |
| 背景平移 | 按住背景直接拖动视图，无延时、无模式切换；平移不改文档、不产生撤销记录               |
| 元素操作 | 单击选择，按住元素拖动元素，双击文字编辑；不能因为此前的画布操作而进入持续的手型模式 |
| 多选     | Shift+单击多选；Shift+拖动背景框选；Alt+单击深入选择                                 |
| 背景对象 | 文档底层铺满画布的矩形可作为背景平移；通过图层树或 Alt 仍可选择并编辑它              |
| 字号输入 | 输入数字即可，单位明确；不能再次出现合法字号被 CSS 校验错误拒绝                      |
| 属性面板 | 模块独立折叠；首次使用时「布局」默认折叠；切换元素不强迫用户反复展开相同模块         |
| 输入焦点 | 编辑文本或数值时，Delete、方向键、复制粘贴等优先作用于输入框                         |

Space+拖动可作为从元素上临时平移的快捷方式，但不是基本操作的前置条件。

## 4. 编辑能力需求

### E01 · 文字与属性编辑可靠性 — P0

**问题：** 文字和数值是最高频操作；单位、焦点、校验或样式继承上的小错误会直接阻断精修。

- 字号输入默认 px；合法数值、显式单位和显示值保持一致，拒绝无效输入时保留原文档。
- text/tspan 内容、字体、字号、字重、颜色、对齐及行距可分别修改。没有实际变化时不生成历史项。
- 普通 text 与平铺 tspan 分别编辑，保留不相关段落、定位属性和其他图形。
- 对嵌套 tspan、textPath、逐字定位等结构，明确说明哪些能改、哪些不能改，并提供源码入口。
- 中文输入法组合期间不提前提交；焦点内快捷键不触发画布删除、移动或全选。

**验收：** 修改一个标题和一个多行段落后，未编辑的 tspan 与其他元素保持原样；中文、英文、标点和特殊字符正确导出；字号编辑能撤销重做，选框同步更新。

### E02 · 多行文本与可控换行 — P1

- 对普通 text 提供明确的多行编辑，支持新增、删除行及统一行距。
- 对可安全识别为「逐行布局」的平铺 tspan 提供行管理；对字符级排版或混合样式保留逐段编辑，不能直接重写。
- 增加可选的「排版宽度」与自动换行，默认关闭；用户主动指定后才重新排版所选文字。
- 提供「缩小字号以适应指定宽度」的一次性命令，显示预览和最小字号限制，不自动改动全文。
- 使用实际 SVG 字体测量；字体未就绪或结构不支持时提示，不用 HTML 自动布局替代原 SVG 布局。
- 溢出判断只针对用户指定的宽度或明确选定的容器，不把所有几何重叠当作错误。

**验收：** 长中文标题能在指定宽度内换行；导出为标准 text/tspan，重导入后行数、位置和字号一致；取消预览或撤销恢复原结构；未主动启用换行的导入文档不变。

### E03 · 精确变换与约束 — P0

- 保留当前嵌套 SVG Transform 坐标转换，补测负坐标、旋转、非等比缩放、不同 viewport/viewBox 比例和非零原点。
- 尺寸栏提供比例锁定；明确显示使用文档坐标及外接矩形尺寸。
- 缩放、旋转、方向键微调与数值输入采用一致的参照系；旋转增量与绝对角度不能混淆。
- 零宽/零高线条使用端点属性或端点手柄，不强行套用矩形缩放。
- 遇到奇异矩阵、不可安全修改的 CSS Transform 或合成效果，停止该次操作、恢复原状，并指出替代入口。
- 变换过程中不允许出现 NaN、反向跳动、选框与对象脱离、未选元素被修改。

**验收：** 在多级 rotate/scale/matrix 下拖动方向与距离正确；多选整体移动正确；完整一次手势仅一个历史项；无效操作不留下部分修改。

### E04 · 容器外框调整 — P1

**问题：** 当前整组缩放会连同文字一起缩放，无法替代「把卡片加宽一点」。

- 对明确选中的 rect 提供「调整外框尺寸」，修改其几何宽高，保持同组文字、图标的字号与尺寸。
- 对分组提供「选择背景矩形」的快捷入口；有多个候选时展示候选，不能凭几何包含关系擅自指定。
- 区分「整组缩放」与「调整外框」，通过上下文命令或明确控件表达，不引入持续的画布工具模式。
- 可以继续使用原有对齐命令摆放文字；1.0 不承诺外框变更后自动重排所有子元素或连接线。

**验收：** 将卡片背景从 220 加宽到 280 个文档单位，标题字号、图标尺寸不变；导出与撤销正确；复杂 Transform 下不支持的外框操作应明确限制。

### E05 · 批量样式与继承反馈 — P1

- 多选元素按**计算后的实际值**显示共同值；不同值显示「混合」，不能仅比较显式属性字符串。
- 统一修改填充、描边、透明度、圆角；文字相关批量命令只作用于明确选中的文字或经用户选择的文字子集。
- 颜色入口支持颜色值、透明度、none；最近使用颜色作为本地 UI 偏好保存。
- 明确标注属性来自继承、class 或显式覆盖；支持移除当前覆盖、恢复继承。
- 修改分组时，说明具有独立样式的子元素可能不会跟随；不能为了让效果看起来生效就覆写所有后代。
- 色板拖动与连续预览按一次操作提交，Esc 取消，不生成大量撤销快照。

**验收：** 三个不同填充的矩形显示「混合」，一次改色只改填充；一次撤销恢复各自原色；清除覆盖恢复原 class/继承效果。

### E06 · 对齐参照与精确间距 — P1

- 增加「对齐到」：当前选择边界、关键对象、画布；关键对象在画布上明确标出。
- 保留现有边缘/中心对齐和均匀分布，增加指定水平/垂直净间距。
- 调整间距只平移对象，不隐式缩放对象；不足三个对象时解释均匀分布不可用的原因。
- 拖动时展示对齐线和关键间距读数；临时禁用吸附应有明确提示。
- 避免用过多参考线覆盖图形；只显示当前最相关的匹配。

**验收：** 三张宽度不同的卡片可设置为 24 单位净间距，宽度不变；切换参照后对齐结果一致、可预测；撤销恢复原位置。

### E07 · 可视化连接线与箭头 — P1

- line 提供两个端点手柄；polyline 提供端点和已有拐点手柄。
- 手柄位置通过实际矩阵映射，拖动只更新目标端点或拐点。
- 箭头使用可视化选项，列出文档已有 marker，并提供少量基础箭头样式；不要求用户手写 `url(#...)`。
- 创建 marker 时保证 ID 唯一、引用有效；改一个连接线的箭头不能意外修改其他共用 marker 的连接线。
- 提供描边粗细、实线/虚线、端点样式等明确控件。
- 复杂 path 继续整体移动、缩放、改样式；不自动猜测它连接了哪个节点。

**验收：** 嵌套变换下拖动一个端点，另一端点不变；编辑一条线的箭头不影响其他线；下载并重新导入后端点、折线和箭头一致。

### E08 · 图层与选择协同 — P1

- 画布选择后展开必要祖先并将对应图层滚动到可见位置，保留用户其他展开状态。
- 搜索覆盖名称、ID、类型和文字内容，搜索结果显示所在分组路径。
- 支持同父级拖动排序；跨父级移动暂不提供，避免继承和坐标语义发生意外变化。
- 多选图层可批量隐藏、锁定、重命名分组；锁定状态与文档可见性分别表达。
- 提供「选择下方对象」候选列表，用于重叠元素；保留 Alt 直接深入和图层树两种入口。
- 大型树采用按需展开和必要的可见行渲染，不因每次指针移动重建完整树。

**验收：** 从画布选中三层分组里的文字，图层可定位；锁定祖先后子元素不可误拖；同级排序不改变坐标；隐藏/显示和文档修改可撤销。

### E09 · 安全源码编辑 — P1

- 将现有只读源码窗口升级为可编辑，保留「复制」「下载」入口。
- 应用前解析、校验并安全清理；显示错误位置（可获得时）、原因和清理影响。
- 未应用的源码不进入可见 SVG DOM；错误不替换当前文档。
- 采用「应用 / 取消」，一次应用一个文档历史项；保留视口，选择仅在能可靠映射时保留，否则明确取消选择。
- 涉及 ID、defs、marker、CSS 的变更检查引用，不用整段字符串替换来修补 XML。
- 直接 SVG 导入与「应用源码修改」采用不同的历史语义，不能因为应用源码清空既有撤销链。

**验收：** 能通过源码修改一个受限文本结构；非法 XML、危险内容和失效引用给出明确反馈；取消不改文档；应用后可撤销、重做和继续可视化编辑。

### E10 · 常见图形选择与直接插入 — P1

**目标：** 原稿缺少一个框、节点、箭头或标签时，直接在编辑器中补上，不需要重新让 AI 生成整张图或手写 SVG。

- 顶部提供明确的「插入 → 图形」入口，以带名称的缩略图选择图形，不要求用户记住图形名称或 SVG 元素类型。
- 1.0 至少覆盖：矩形、圆角矩形、圆形、椭圆、菱形、三角形、直线、直角折线、单向箭头、双向箭头，以及独立文字标签。
- 点击缩略图即可按合理默认尺寸插入当前可见画布中心；也可将缩略图拖入画布，在释放位置插入。插入后自动选中，立即允许移动、缩放和属性编辑。
- 插入是一次性动作，不进入持续绘图模式，也不恢复选择/手型切换；连续添加通过再次插入或重复元素完成。
- 默认进入当前明确的、未锁定且坐标可逆的编辑分组；不在分组内时插入文档根层。当前层级不能安全插入时解释原因，并提供「插入到文档层」选项，不能静默放进别处。
- 新对象使用标准 SVG 元素，默认填充、描边和文字样式明确，避免被导入文档的根样式或 class 意外隐藏、改色。不得改写原有元素的样式。
- 新建箭头与 E07 共用 marker 管理，ID 唯一且引用有效；新建图形支持现有对齐、分布、分组、复制和图层操作。
- 文字标签保持为可编辑 text；若用户为图形添加标签，图形和文字可显式组合为 g，仍能分别选择和编辑，不转成图片或文字轮廓。
- 一次插入仅一个历史项；拖入取消、释放到画布之外或按 Esc 取消时不残留节点或定义。

**验收：** 无需源码，分别选择并插入圆角矩形、菱形、箭头和文字标签，放到指定位置后改色、改字、对齐并组合；在缩放和平移后的视口及嵌套变换分组内，插入位置正确。一次撤销删除整个新增对象，重做完整恢复；导出重导入后仍可分别编辑，不影响原图。

### E11 · Icon 浏览、搜索与插入 — P1

**目标：** 为架构图、流程图和信息卡片补充图标，减少在外部网站找素材、复制 SVG 和手工定位的步骤。

- 与图形共用「插入」入口，在独立的「Icon」分类中展示图标网格、名称、类别及搜索。
- 内置一套风格一致的 SVG 图标，首批覆盖计算机、服务器、数据库、云、网络、用户、文件、设置、方向及状态等技术图表常见类别；支持中文/英文名称或关键词搜索。
- 内置图标随应用提供，不依赖在线图标服务、远程资源或图标字体；搜索与插入可离线使用。发布前记录图标来源、版本和许可，并按许可要求交付声明。
- 点击图标直接插入当前可见画布中心，也支持拖入定位；与 E10 共用插入坐标、目标层级、默认样式、取消和事务规则。
- 插入结果为文档内自包含的原生 SVG 图形，默认作为独立命名分组选择，支持改色、调整尺寸、旋转、复制和图层管理。单色线性图标可调整描边粗细；多色图标保留原色，不用统一改色静默覆盖所有路径。
- 默认等比缩放，并提供明确的比例锁定控件；图标内部细分路径可通过现有分组深入方式选择，不引入专用编辑模式。
- 提供「导入 SVG 图标」入口，将本地 SVG 或粘贴的 SVG 作为新增对象插入，**不能替换当前文档**。复用现有安全清理，去除独立文档外壳时保留其 viewBox 映射、样式和有效内部定义。
- 自定义图标的 defs、渐变、clipPath、marker 等引用需要隔离、重命名及校验；插入同一个图标多次不能 ID 冲突或影响原图。被清理或受限的内容按 U06 展示。
- 提供最近使用的图标列表；仅保存必要的本地偏好或安全资源，不将图标面板状态写入导出 SVG。

**验收：** 搜索并插入一个数据库 Icon，拖入一个云 Icon，调整颜色和等比尺寸后与卡片文字对齐；断网后内置图标仍能插入。再连续插入两次含渐变或裁剪的自定义 SVG 图标，原图和两个实例的资源互不干扰。各次插入可独立撤销重做；导出文件独立打开无需外部请求，重新导入后仍为可编辑图形。

## 5. 用户体验需求

### U01 · 统一画布交互 — P0

- 不恢复选择工具和手型工具的切换，不依赖 V/H 模式，不引入延时长按。
- 明确区分背景平移、元素移动、控制点缩放和 Shift 框选。
- 进入/退出分组、重叠选择和背景对象编辑都有可见反馈。
- 拖动超出画布边界、失焦、Esc、pointercancel 后正确结束或回滚，不能留下持续拖动状态。

**验收：** 不切换任何工具，连续完成平移、选中卡片、移动卡片、改字、框选；背景拖动不写 SVG，不清除选择，也不占用一次撤销。

### U02 · macOS 触控板导航 — P1

建议默认方案：双指滚动平移、捏合缩放；鼠标滚轮行为可配置。与当前默认滚轮缩放相比，这是 1.0 的导航方案；当前实现与验收状态见实施进度。

- 区分普通滚动与浏览器提供的捏合缩放事件，避免一次手势同时触发页面缩放和画布缩放。
- 缩放围绕指针位置或手势中心，保持内容稳定；保留 Fit、100% 和倍率输入入口。
- 横向/纵向滚动、惯性滚动与侧栏滚动不冲突；指针位于属性面板时优先滚动面板。
- 偏好设置可选「滚轮缩放」或「滚轮平移」，保存在本地；不靠浏览器猜测强制切换用户习惯。

**验收：** 在实体 Mac 触控板上完成双指平移、捏合、按住背景拖动，画面不跳、不误框选；Chrome 和 Safari 分别验收，不能用鼠标自动化代替实体手势结论。

### U03 · 属性面板与输入 — P0

- 所有模块独立折叠；布局首次默认收起，其余按上下文展开。
- 模块折叠状态、侧栏宽度/开关、网格和导航偏好与 SVG 文档分开保存。
- 选择变化、撤销重做和恢复文档不重置用户的模块展开习惯。
- 数值支持小数、明确单位、键盘步进和 Shift 大步调整；Enter 提交、Esc 恢复。
- 输入错误显示在对应字段附近，保留待修正内容和原文档；不只弹出抽象的「属性无效」。
- 面板标题支持键盘与可访问状态；折叠内容不进入 Tab 顺序。

**验收：** 连续切换文字、矩形、线条后，通用模块的折叠状态保持；错误字号不改文档；键盘可以展开模块、编辑数值并撤销。

### U04 · 操作事务与反馈 — P0

- 一次拖动、一次文字提交、一次颜色预览、一次连续键盘微调分别对应可理解的历史项。
- 连续输入的合并规则明确，避免一按方向键就产生大量快照，也避免不同动作被合并得无法单独撤销。
- 常用命令提供文字提示及 macOS 快捷键；不可用命令解释原因。
- 成功提示短暂、不遮挡正在编辑的内容；需要修正的错误保持到用户处理或关闭。
- 不给每个可撤销操作增加确认；仅在可能丢失未导出内容、且无法可靠保留副本时确认。

**验收：** 连续调整字号、颜色和位置后，撤销顺序符合实际操作；取消预览恢复操作前状态；提示不挡住底部缩放、当前文字或提交按钮。

### U05 · 文档保护与导出状态 — P0

- 区分「有未导出修改」「已写入本地恢复副本」「已发起导出」，不能把 localStorage 恢复称为文件已保存。
- 导入失败保留原文档；成功替换前保留旧文档恢复副本。副本无法写入且原文档有未导出修改时，提供导出/取消选项。
- 本地恢复采用原子更新与版本校验；大文档超出存储容量时明确提示并允许手动导出，不能静默放弃。
- 恢复后提示来源和时间，允许恢复副本或从新文档开始；不会自行覆盖用户正在编辑的内容。
- 导出默认沿用文件名，可重命名；下载和复制失败可恢复，并保留当前工作。
- 不承诺浏览器下载 API 无法确认的文件落盘状态。

**验收：** 编辑后刷新可恢复；模拟存储不足、损坏记录、导入失败和下载失败时文档不丢失；恢复和导出的状态文案真实。

### U06 · 安全与兼容性报告 — P0

- 区分：已保留、保留但限制编辑、已清理、导入被拒绝。
- 报告尽可能定位到元素类型、ID 和原因；能解释外观可能发生的变化。
- 文档因安全清理发生实际损失时，在替换前展示影响，允许取消并保留原工作；完全安全的正常导入不反复确认。
- 字体缺失、外部字体被阻止和字体实际回退分别说明；不宣称无法可靠检测的字体一定已安装。
- 不为兼容某个示例绕过脚本、事件、外部资源、CSS URL、命名空间及规模限制。

**验收：** 恶意 SVG 不执行、不发外部请求；被清理的内容可解释；正常内部渐变、marker、clipPath、mask 和 use 不误报为危险内容。

## 6. 质量与发布门槛

### Q01 · 回归素材与保真 — P0

在现有五类素材基础上，扩充到至少 20 份固定回归文档，覆盖：

- 中文和英文、多行及混合 tspan、字体回退、特殊字符。
- 嵌套矩阵、负坐标、不同宽高比例、非零 viewBox 原点。
- CSS 继承与覆盖、渐变、marker、clipPath、mask、filter、use。
- 重叠对象、隐藏/锁定分组、零尺寸线条、大型图层树。
- 非法 XML、脚本、事件、外部资源、引用循环和超限输入。
- 新插入的常见图形、文字标签、内置 Icon，以及多次插入含内部定义的自定义 Icon。

每个新增编辑需求至少有对应逻辑或浏览器验收用例。对渲染敏感的修改必须对比同浏览器、同尺寸、同字体下的原生 SVG 预览；安全清理导致的预期变化单独验证，不能混入「保真通过」。导出文件不得包含 Overlay、选框、视口网格和 UI 偏好。

### Q02 · 浏览器与设备 — P0

发布目标为 macOS 桌面 Chrome 和 Safari，记录实际版本与设备。主流程需同时完成自动化回归和实体触控板验收；Safari 不能只依赖 Chromium 测试或 WebKit 模拟结果作结论。手机编辑、Firefox 和 Windows 完整验收暂不作为 1.0 承诺。

### Q03 · 性能与可访问性 — P1

以下是**待实测的建议性能目标**，不是当前成绩：

| 场景                   | 建议目标                                          | 验证口径                                              |
| ---------------------- | ------------------------------------------------- | ----------------------------------------------------- |
| 2,500 个普通图形       | 导入后首个可操作画面 ≤ 1 秒                       | 从已读取 XML 到安全清理、挂载和首帧完成，不含文件读取 |
| 10,000 个普通图形      | 首个可操作画面 ≤ 3 秒                             | 相同口径；受当前文件/节点限制约束                     |
| 典型文档选择与属性反馈 | P95 ≤ 100 ms                                      | 固定素材、至少 100 次交互，记录输入到视觉更新         |
| 拖动与平移             | 典型素材目标 60 fps，不出现持续超过 100 ms 的停顿 | 记录参考机、浏览器、DPR，使用实际帧与长任务数据       |
| 大型图层树             | 选中后能及时定位，不整棵重建                      | 同时观察 DOM 数量和交互延迟                           |

不因性能目标放宽安全限制；复杂滤镜等高成本素材单独分档。记录硬件、浏览器、视口、DPR、素材规模及测量次数，避免把不同环境成绩混为一谈。

桌面可访问性要求：键盘可完成导入、图层选择、属性编辑、撤销及导出；所有关键图标有名称、焦点可见；状态变化可被辅助技术理解；200% 浏览器缩放下仍能找到核心操作。

## 7. 不纳入 1.0 的功能 — P2 / 后续版本

| 候选                                   | 暂缓原因                                                                      |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| 自动识别所有卡片、节点及连接关系       | 对任意 AI SVG 不可靠；1.0 优先显式分组与用户指定对象                          |
| 节点移动后自动重路由连接线             | 需要可信的连接语义，不作为端点编辑的前提                                      |
| 完整自动布局、碰撞自动修复             | 容易改变原稿意图，先解决精确手动排版                                          |
| 复杂 Path 节点、钢笔、完整富文本       | 明显扩大为通用矢量编辑器                                                      |
| 一键展开任意 use 或取消任意效果分组    | 引用、样式和合成外观难以普遍无损分发                                          |
| AI 修改、模型接入、自动生成图形        | 当前精修闭环优先，不增加 API、账号和费用负担                                  |
| 大型专业图形库、模板市场、复杂绘图工具 | 1.0 已包含 E10 基础图形与 E11 Icon 插入；复杂 BPMN/UML 库和市场化扩展后续评估 |
| PNG/PDF 等附加导出                     | 标准 SVG 可靠性优先，可在后续评估                                             |
| 云存储、协作、账号、手机专用模式       | 与当前轻量、本地优先定位不符                                                  |

## 9. 1.0 完成定义

以下场景均应使用代表性 SVG 完成，存在阻塞时不发布稳定 1.0：

1. 粘贴含渐变、marker、嵌套分组和多行文字的 AI SVG，正确显示并理解清理报告。
2. 不切换工具，通过触控板平移、缩放、选择卡片、进入子层级并退出。
3. 将过长标题调整到指定宽度，增加一行文字，保持其他段落和图形不变。
4. 扩大卡片背景而不放大标题；再调整三张卡片的对齐和净间距。
5. 批量修改颜色，清除一个元素的样式覆盖；撤销后恢复各自原值。
6. 可视化移动直线或折线端点并选择箭头，其他连接线不变。
7. 在图层中定位、隐藏、锁定和排序，恢复后视觉位置正确。
8. 通过源码修改受限结构，验证非法输入不替换文档，合法应用可撤销。
9. 经历一次导入替换、刷新恢复和模拟存储不足，用户始终有明确的工作保留或导出路径。
10. 下载标准 SVG，在目标浏览器直接打开，重新导入后继续修改；内部资源引用有效，不含编辑器辅助 UI。
11. 从缩略图面板选择常见图形，点击直接插入或拖入指定位置，补上箭头和文字标签，并使用现有布局工具完成编辑；全程无需切换选择/手型工具。
12. 搜索并插入内置 Icon，插入自定义 SVG 图标；多次插入不冲突、不替换原文档，离线可用，导出后仍是自包含的可编辑 SVG。

发布时逐项列出需求 ID、完成状态、测试证据、已知限制及延期项。未完成的 P1 必须明确调整版本范围，不能用「已有按钮」或「代码已经存在」代替验收。
