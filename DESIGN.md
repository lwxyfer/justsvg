# JustSVG design

## Overview

JustSVG is the user-selected identity for an open-source, SVG-native diagram creation and editing tool. Its subjects are architectures, flows, infographics and the structure of technical frameworks, products and repositories. Start from styles/templates or imported SVG, edit directly, and retain portable SVG. The diagram-first purpose governs the visual language rather than general vector illustration.

**Just diagrams. Just SVG.** / **把复杂系统，画清楚。**

The user's pinned light, professional desktop editor direction governs. Mode: Operate.
Three columns: 232px layers, flexible native SVG canvas, 280px inspector. A 56px file bar, 44px action bar, 30px status bar. At narrower desktop widths panels collapse independently.
System sans-serif UI; monospace for coordinates, XML and numeric measurements only. Neutral white surfaces, pale gray canvas, #2563eb interactive blue. Fine 1px dividers, 4–8px control corners, no decorative cards. Lucide icons at 16px. Tooltips include shortcuts. Focus-visible outlines, semantic controls, explicit disabled states.
The default authored example is an editable architecture diagram with clear groups and internal gradients/markers. It demonstrates the actual document engine, never a raster mockup.

The homepage extends JustSVG’s identity in Persuade mode through four connected chapters from the approved A/B and continuation compositions: native SVG construction, whole-page brand styling, local Skill task preparation and actual SVG editing. The editor remains Operate. “draw.io 的开源替代。” states the product category directly; supporting copy names AI-generated architecture diagrams, flowcharts and infographics, followed by visual editing. The primary editor entry remains, while the secondary link leads to the SVG Skill chapter. The three specimen captions now explain the dynamic brand count, native editable SVG and visual editing; native artwork shows brand choices, vector geometry and a node/property selection respectively. The heading uses heavy self-hosted JustSVG Sans (a renamed variable Noto Sans SC subset) with tight spacing; homepage text uses that local sans family, while the identity wordmark, existing editor and example artworks preserve their own typography. The serif homepage face is unused. Brand grammar changes surfaces, text hierarchy, control geometry and diagram materials while retaining the same technical semantics; these homepage treatments do not redefine artwork or editor rules.
