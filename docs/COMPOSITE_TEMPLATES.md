# JustSVG 组合图

组合库面向技术架构、工作流程与技术信息表达，内置 24 个原创 SVG 模板。素材随应用提供，无在线模板 API、字体或图片依赖。沿用项目 MIT 许可。

## 使用

1. 左侧「插入 → 组合图」，展开分类或搜索，例如 `RAG`、`CI/CD`、`泳道`、`路线图`。
2. 点击预览插入当前视口中心，或拖入指定位置。进入分组时插入当前分组。插入保持当前文档、默认锁定整体比例、一次操作一个历史项。
3. 若需要整张新图，点击预览下方「作为新图稿」。模板在新标签中打开，原文档及其撤销历史保留；模板尺寸成为新画布尺寸，自动适应视图。
4. 插入后双击组合背景进入子层级，继续双击容器深入节点；双击文字直接编辑。也可 Alt+点击精确选择形状、文字或连线，通过图层面板选择被遮挡的元素。Esc 退出层级。
5. 调整内容、样式与布局，再从「导出 SVG」下载。导出文件是自包含的标准 SVG，可在浏览器直接打开或重新导入继续编辑。

## 编辑边界

- 这是可编辑的起点，示意节点和技术关系需按实际系统修改。指标、责任人、路线图交付和方案对比保留待填写占位，不生成虚构业务数据。
- 容器按业务语义分组。新图稿的节点直接存在于原生 SVG 图层中；插入已有图稿时增加一层命名分组，避免散落为多个独立选中对象。
- 连线使用原生 polyline、内部 marker 与 `data-sf-*` 节点关联。新插入模板中端点明确的连线跟随节点移动、缩放与对齐，带标签的模板连线同步移动标签；路线保留原有直角通道，不做障碍物避让。旧版已保存的模板可选中节点，使用「连接关联 → 关联相邻箭头」建立关联。
- 不自动换行或重排卡片。长标题可调整字号、使用现有文字排版功能，或修改卡片尺寸。
- 使用本机 Arial / 中文回退字体；不同系统的实际字宽可能不同。当前 Chrome 自动化验证全部模板文字边界与代表性模板渲染一致性。
- 「作为新图稿」增加独立文档标签，不会重置其他图稿的历史。所有标签共享本地恢复存储额度，localStorage 不是文件备份，仍需定期导出。

## 增加模板

源文件位于 `src/editor/insert/templates/`，按 architecture、flows、infographics、components 拆分。`drawing.ts` 提供文字、节点、容器、判断节点与折线的小型 SVG 构建函数；`index.ts` 汇总进素材目录。

- 模板需要稳定且唯一的 `template-*` ID、中文名称、分类、说明、搜索词和明确的宽高/viewBox。
- `drawing.ts` 给节点和容器暂存几何边界，由 `bindings.ts` 在素材构建时为明确端点生成内部节点引用和归一化锚点，随后删除暂存边界。运行时按背景形状的实际 SVG 坐标跟随，不使用静态边界。标签引用同一连接线 ID；插入及复制时统一重写内部关联。
- 使用原生 SVG，多节点按语义分组。模板无需图稿大小的白色背景矩形，留空区域可继续平移画布。
- 文字保留为 text；内部引用使用 `#id`，不使用外部图片、字体或执行内容。通用绘图函数按节点类型为 ID 添加前缀，避免重复及 DOM 命名冲突。
- 受信任的 1:1 模板可插入为单一原生 g。插入前仍执行完整安全清理，隔离计算样式、重写 ID 与资源引用，避免污染原图。任意自定义 SVG 继续保留嵌套 viewport 语义。
- 更新目录和测试预期，执行 `npm run build`、`npm run lint`、`npm test`、`npm run test:e2e`。

浏览器回归会逐一插入所有模板、测量文字与节点边界、检查内部引用和完全撤销。代表性模板额外进行原生渲染像素对比；端到端覆盖编辑、真实下载、独立打开、重新导入、恢复原文档，以及变换分组下重复插入。
