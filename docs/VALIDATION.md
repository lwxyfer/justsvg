## 单元验证

- 五类 SVG 的解析及导出再解析。
- 渐变、style、mask、clipPath、filter、marker、symbol/use 和嵌套 Transform 保留。
- 非法 XML、DTD、错误命名空间、过大文档、过深嵌套、过大/无效 viewBox 拒绝。
- script、事件属性、foreignObject、动画、外部资源和 CSS URL 阻断。
- 安全 raster data URL 保留，SVG data image 拒绝。
- use 循环检测，CSS 转义及 @规则限制。
- 安全 CSS Transform 保留并报告编辑限制。
- 几何 union、框选相交、最近边界吸附。
- 保留 tspan 结构及坐标的文字编辑、复杂文本拒绝。
- 事务提交/回滚、空事务、历史容量、redo 分支清理。
- 单个元素属性修改不影响其他元素，祖先锁定生效。
- 历史恢复保留稳定编辑器身份和会话锁定。
- CSS AST 引用改写区分 ID 与颜色字面量，粘贴样式作用域隔离。

## 浏览器验收

1. **完整 MVP**：粘贴架构图 → 拖动卡片 → 撤销重做 → 双击修改标题 → 多选顶对齐 → Alt 选择背景改色 → 撤销重做 → 实际下载文件 → 新浏览器页直接打开下载的 SVG → 重新导入 → 继续方向键编辑。
2. **嵌套变换**：带 rotate 和非等比 scale 的子矩形方向键移动正确；拖动缩放点有效；一次缩放一个历史项；未选择的矩阵分组不变。
3. **组合与分布**：多选分布、组合与取消分组后保留实际屏幕几何；复制卡片的 gradient URL 与定义 ID 对应。
4. **多行文本**：只改首个 tspan，第二段内容、dy 保持；文本框内方向键/Delete 不触发画布操作；撤销恢复。
5. **安全运行**：恶意 SVG 不执行注入变量、不请求 example.invalid 外部资源；兼容性报告展示；非法 XML 产生可读错误。
6. **复杂往返**：defs、CSS、蒙版、裁剪、marker 和 use 导出再导入后保留实际几何及非零原点 viewBox。
7. **视口**：0.5/1/1.5 倍缩放下 Overlay 紧贴真实图形；紧凑桌面可使用导出和面板开关。
8. **原生视觉回归**：三类 SVG 的直接浏览器渲染与编辑器导入结果以 pixelmatch 比较；阈值 0.15，有效差异像素比例小于 0.1%，允许浏览器合成产生的微小抗锯齿差异。
9. **其他输入方式**：本地文件 input 上传、框选同层图形与线条、搜索与锁定/解锁、隐藏/显示、ClipboardEvent 粘贴、Space 平移。
10. **剪贴板资源**：复制 use 后引用新 symbol；粘贴 `rect{fill:red!important}` 不改变原文档卡片颜色。
11. **大型 SVG**：2,500 个真实 SVG rect 保持在 DOM 中；整个分组可选、可方向键移动、可导出。
12. **viewport / viewBox 比例**：保留显式宽高与默认 preserveAspectRatio；原生截图匹配；一个文档单位映射到正确屏幕距离。
13. **根节点效果**：根 transform 和 opacity 在重复图形时不重复应用；CSS Transform 的几何编辑被明确拒绝，原文档保留。

## 取舍与测试边界

- 源码、逻辑和浏览器测试均已完成，未留下阻塞核心闭环的问题。
- 本次没有在 Firefox、Safari、手机触控设备或 Windows 字体环境执行测试，不能据此宣称这些环境已验收。
- 图层树沿用原始逻辑分组，未引入自动语义识别。性能测试使用代表性 2,500 元素文档，不代表所有 15,000 节点文档都具有相同性能。
- 截图测试覆盖代表性输入，不构成对任意第三方 SVG 的无损往返保证。
- 复杂文本、组级合成效果、CSS Transform、外部资源等限制见 README；界面提供相应提示。
- 没有引入服务器、云服务、账号、AI 模型或遥测。
